# 检查并修订防御性写作

防御性写作把篇幅花在预先回应质疑、重复免责或交代作者的尝试过程上，读者却难以找到研究主张、支持它的证据和实际适用范围。优先看摘要、引言的贡献段、结果解释和讨论。全文审查时，核对同一主张在这些位置是否一致。

## 先确定当前能说什么

为目标段落找出证据支持的发现，并定位到具体结果、对照、推导或来源。记录改变读者判断的条件，包括比较对象、样本和设置、不确定性、竞争性解释，以及影响结论的反证。根据段落任务组织材料，摘要突出主要发现，方法交代可复核的条件，讨论解释边界及其后果。

## 判断一句话的作用

暂时移开候选句，检查读者会不会误解主张的范围、确定性、因果关系或证据状态，也检查该句是否提供必要的复现信息。按原文功能决定怎么改。

| 原文情形 | 怎么处理 |
| --- | --- |
| 多句泛泛说结果可能有用、应谨慎解读 | 删去空泛免责，写出实际发现，并注明影响解读的条件。 |
| 先回答正文主张并未引出的假想质疑 | 写清论文实际主张及其范围。真实的竞争性解释留在会影响结果解读的位置。 |
| 同一局限或自我辩护在多节重复 | 在相关证据旁解释一次。摘要或结论需要靠它准确概括发现时，保留简短限定。 |
| 按运行顺序罗列失败或未定的分析 | 按研究问题组织结果，写清它们排除了什么、还无法区分什么。影响中心结论的反证留在正文。 |
| 限定语给出真实样本、比较条件、效应不确定性或必要例外 | 保留限定语，并放在读者据此解释主张的位置。 |
| 删除免责后暴露核心证据缺口 | 缩窄至实际观察，或把缺口交给作者。给出原文位置、需要核实的问题、所需材料和可能影响的结论。 |

## 修改后复核

- 对照原文、图表和实验设置，确认新句没有提高确定性、因果性、普遍性或创新性，保留数值、单位、样本边界和必要引用。
- 核对反证和不确定结果在改写后仍能影响读者判断。原稿存在冲突时，指出冲突及需要核实的材料。
- 整篇改写时，回看摘要、结果和结论对同一主张的表述。局部改写时，只在相关位置核对证据，按用户指定范围交付改稿。
