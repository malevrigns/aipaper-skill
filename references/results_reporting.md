# 让结果成为论证

正文回答：比较了谁，在什么设置下，有多大变化，支持什么，边界在哪里。关键数值与不确定性可以留在句子中；重复的逐设置明细通常适合表格。附录承接可复核细节，不能隐藏核心反证。

| 内容 | 检查方式 |
| --- | --- |
| 同一列指标 | 精度、单位、分母和方向一致，以实际分辨能力选择位数 |
| 不同指标 | 分别选择精度，不强制 accuracy、runtime 和 p 值小数位相同 |
| 效应大小 | 区分绝对差、百分点与相对百分比，明确参照值 |
| 不确定性 | 说明 SD / SE / CI、独立重复数及汇总层级，勿相互替换 |
| 显著性检验 | 说明比较和适用条件，小 p 值不等于效应大或实际重要 |
| 很小的值 | 采用合适精度或科学计数法，勿把非零 p 值四舍五入成零 |
| 多组探索 | 交代探索性质及适用的多重比较处理，勿事后包装为预设验证 |

仅有均值和标准差时，不能在不了解样本量、独立性及方法的情况下补造 CI。完整名称是 **confidence interval**，不是 confidential interval。

## 三种结论

- **支持**：当前证据在给定设置下支持具体变化，说明范围。
- **反证或有信息的负结果**：预期未成立，但足以约束机制或范围；说明如何改变主张。
- **仍不确定**：现有精度或设计不能区分两种解释；不能改写为“相同”，也不能仅凭它断言研究无价值。

## 参考依据

以下支持统计解释原则，不作为机器学习会议的统一格式要求：

- [ASA：统计显著性与 p 值声明（2016）](https://www.amstat.org/asa/files/pdfs/p-valuestatement.pdf)：判断不应只依赖显著性阈值，p 值不度量效应大小或研究重要性，透明汇报是推断的基础。
- [Nature Human Behaviour：Points of significance（2023）](https://www.nature.com/articles/s41562-023-01586-w)：显著性本身不足以说明科学或实际意义。
