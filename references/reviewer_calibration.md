# 防止“写得很谨慎”获得虚高评价

本项目源于维护者对多位审稿人的调研，以及对 2026 年大量 AI 论文的阅读观察。相关反馈促使项目关注一种审查偏差：过分重视措辞谨慎、统计细节齐全时，研究问题和证据不足可能被忽略。以下将这些观察转为具体的审查自检方法。

## 在文风之前判断内容

先记录问题、贡献、关键证据和未解决点，再读语言与图表检查结果。不要从词频、图表数量、limitation 长度生成论文评分。

| 容易给出的评价 | 应核实的内容 |
| --- | --- |
| “统计分析充分” | 哪项主张得到支持？独立重复、对照、假设与效应解释是否合理？ |
| “claim 很谨慎” | 主张是否清楚、有价值且可检验？范围与证据是否一致？ |
| “诚实报告不足” | 不足如何影响中心结论？结论是否相应调整？ |
| “实验很全面” | 各实验回答哪个问题？是否重复同一个无法判断的比较？ |
| “语言很流畅” | 能否据此复述实际方法、证据与研究理由？ |

## 两个反事实检查

**保留证据，换一种文风。** 简洁表达之后，质量判断是否变化过大？如是，回到证据解释，避免奖励文风。

**保留文风，替换证据状态。** “支持核心主张”变为“无法区分解释”后，原来的优点是否仍被机械保留？如是，重新核对依据。

这是审查者的自检，不要求修改原稿或伪造实验，不把模型输出当真实审稿人评分。

## 给优点也贴证据

统计充分、贡献清晰、边界诚实都需要具体位置和影响说明。没有材料支持时不列。可以只有一个核心优点、两个主要问题，不为模板凑数。
