# 图表检查清单

在最终栏宽或页面尺寸下看图。只有抽取文本时标为“未检查”，不能据此判断留白、字号、线条冲撞或清晰度。

| ID | 检查项 | 记录什么 |
| --- | --- | --- |
| F1 | 方法是否能被理解 | 文字或伪代码不足时指出需要图解的具体关系；没有框架图不自动扣分 |
| F2 | 数据流和关系 | 箭头起终点、含义、输入输出、循环、条件分支和模块命名 |
| F3 | 信息与尺寸 | 最终尺寸下必要的标签、真正影响可读性的留白与冗余装饰 |
| R1 | 坐标轴、单位和刻度 | 指标定义、单位、对数轴、截断轴、方向、子图可比性 |
| R2 | 曲线与图例 | 遮挡、缺失、颜色和线型难区分；直接标注可替代图例 |
| R3 | 不确定性 | SD / SE / CI 的含义、独立重复数、汇总层级；确定性结果不强制误差棒 |
| R4 | 输出质量 | 最终尺寸下文字、细线与压缩；线条文字优先矢量，位图遵从目标出版方要求 |
| R5 | 数字与样式 | 同一指标精度、单位、字体层级、系列颜色映射 |
| G1 | 未完成元素 | 占位符、缺失标签、乱码；有效来源署名和使用披露应保留 |
| G2 | 来源是否清楚 | 复用图或外部图像是否有必要来源说明，画风差异只能提示核对 |
| G3 | 图文是否一致 | 数值、模块、符号、设置与正文或表格的明确冲突 |
| G4 | 装饰是否影响信息 | 遮挡技术内容，或造成错误的大小与距离暗示 |

关键 CI、效应大小和 p 值可以帮助理解；问题是重复堆积、解释缺失或难以阅读。示意图、照片和统计图各有合适的形式，不要求采用同一画风。

按图号列出“可读性 / 数据解释 / 图文一致性 / 优先修改”。共享字体问题只记一个根因，避免逐图重复扣分。
